# 冻结模型推理一致性报告

## 验证口径

验证同时区分两条路径：一是直接加载冻结 Pipeline，对冻结 Test 工程特征进行复现；二是从每条事件的原始国家、灾害类型、日期和 Magnitude 字段，经独立 API 特征构造器重新形成 15 项 T2 特征后推断。参考对象为冻结的 2022—2023 Test 预测，共 948 条。

## 结果

- Pipeline 成功加载，类别顺序为 Low、Moderate、Severe。
- 输入列名与顺序完全一致。
- 端到端预测类别一致 948/948，一致率 100%。
- 最终回归中三类 `predict_proba` 最大绝对误差为 `2.220446049250313e-16`；重复执行观察到的上界为 `3.3306690738754696e-16`，均属于浮点末位。
- 超过 `1e-12` 容差的概率值为 0。
- 同一 JSON 改变字段顺序后，类别与概率完全一致。
- 结果证明 API 特征构造器复现了冻结测试阶段的输入语义；过程中没有训练、重新拟合或参数调整。

结构化结果见 `test_consistency_results.json`，可复现脚本为 `tests/verify_test_consistency.py`。
