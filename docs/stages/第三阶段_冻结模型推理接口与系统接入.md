# 第三阶段：冻结模型推理接口与系统接入

## 阶段目标

将已冻结并通过复现验证的三级 Random Forest T2 Pipeline 封装为服务端推理接口，并在现有灾害事件数字档案系统中增加最小可靠的“影响等级辅助分析”闭环。

## 技术路线与关键决策

采用“Vite 前端 → 同源 Vercel Python Function → 冻结特征构造器 → 原 joblib Pipeline”的同仓库结构。模型与辅助资产只在模块初始化时加载。模型部署副本采用字节复制，未重新序列化。所有需统计的 HDI、历史频率和 Magnitude 参数均被冻结，API 不访问外部数据源、不调用 `fit`、不随数据库新增记录改变。

历史频率保留严格区间因果逻辑，并使用截至 2023-12-31 的事件时间区间快照。HDI 仅按 ISO3+事件年份精确匹配，1990—2023 之外保持缺失。Magnitude 使用 Development 阶段 8 个固定语义组，其中 7 组满足样本量与 IQR 条件；未知或不合格组不生成 z 值。

## 实现内容

- 新增只读辅助产物、来源哈希及生成脚本。
- 新增 15 项 T2 特征构造器、模型哈希校验加载器和响应构造器。
- 新增健康检查、选项与 POST 预测 Python Function。
- 新增 18 项合同测试、5 项 HTTP 测试、948 条 Test 一致性脚本和运行时测量脚本。
- 在 Hash Router 中加入 `#/user/impact-analysis`，沿用登录状态与终端视觉风格。
- 新增 API、特征映射、冻结资产、前端使用、兼容性、论文和阶段文档。

## 验证结果

- 原 Pipeline 与部署副本 SHA-256 均为 `c4960347d423b1b46065c8e2fc57e1e1656fae11e1198af2fe5c6a734392a9d4`，字节一致。
- Pipeline 加载成功，类别顺序为 Low、Moderate、Severe。
- 冻结 Test 948 条端到端预测类别一致率 100%。
- `predict_proba` 最大绝对误差 `3.3306690738754696e-16`，超过 `1e-12` 的值为 0。
- API 自动化测试 23/23 通过。
- Vite 构建通过；前端 `dist` 不包含模型或 Python 文件。
- 本地固定依赖与冻结资产合计约 311.36 MiB；模型加载约 3.01 秒，热预测约 0.17 秒，工作集约 175.71 MiB。

## 发现的问题与边界

冻结历史频率为了重现 Test 行为，需要使用截至 2023 年的无标签事件区间快照。对 2024 年以后请求，训练阶段没有动态更新或未来回退规则，因此当前实现固定使用 2023 年截止状态并警告；HDI 同样保持缺失。这保障确定性，但限制了未来事件的时效性。

科学计算依赖的本地未压缩体积和约 3 秒模型加载时间提示可能存在云端冷启动风险。尚未通过 Vercel 预览部署验证 Linux wheel 构建体积、内存和超时，因此不能把本地检查等同于生产兼容性结论。
