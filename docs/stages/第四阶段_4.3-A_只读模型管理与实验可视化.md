# 第四阶段 4.3-A：只读模型管理与实验可视化

## 1. 阶段目标与边界

本阶段将原管理端“模型管理”占位页改造为只读的“模型档案与实验结果”页面。页面用于展示当前正式模型、论文相关基线、时间验证、置信区间与未采纳实验结论，不提供模型上传、训练、删除、切换、设为正式模型或部署操作。

冻结 Random Forest T2 Pipeline、15项特征、Low / Moderate / Severe 类别顺序、预测接口合同以及独立测试结果均未修改。未读取 Maturity 数据进行新计算，未创建数据库 Migration，也未改变 Production。

## 2. 实施前审计

- 路由：`#/admin/models` 已存在，并继续由共享 Hash Router 与可信 Supabase Auth `app_metadata.role = "admin"` 守卫。
- 原页面：`src/pages/admin/modelManage.js` 仅调用通用占位页，包含“MODEL CONTROL / RESERVED”文案，没有真实模型数据。
- 数据资产：最终 T2 Manifest、三级 T0—T3 指标、早期四分类 RF/Dummy 指标、LightGBM 历史实验、Development 时间CV OOF、Bootstrap区间、阈值与类别权重搜索均有机器可读 CSV/JSON。
- 口径风险：早期 RF/Dummy 为四分类历史 Validation；T0—T3 为三级 Validation；时间CV为 Development OOF；最终 T2 为锁定后的独立 Test。页面不得跨口径排名。
- LightGBM限制：历史最佳参数曾依据验证集选择，因此其时间交叉验证对比不是完全嵌套的无偏模型选择评估；页面保留该说明。

## 3. 数据注册表

新增离线生成脚本 `scripts/generate-model-registry.mjs`。脚本只读取既有实验产物，不训练模型、不请求网络、不读取 Maturity，生成 `src/data/model-registry.json`。注册表仅包含前端展示所需的非敏感元数据和图表数据，并记录每类数据的源文件。

纳入六个具有研究意义的条目：

| 条目 | 状态 | 评价口径 | 用途 |
|---|---|---|---|
| Dummy Prior | Baseline | 四分类历史 Validation | 早期下界 |
| RF-V1 | Historical | 四分类历史 Validation | 早期基础特征对照 |
| RF-V2 | Historical | 四分类历史 Validation | 早期月份增强对照 |
| RF-T0 | Baseline | 三级历史 Validation | 三级特征消融基线 |
| LightGBM T2 | Candidate | Development 时间CV OOF | 梯度提升候选对照 |
| Random Forest T2 | Production | 锁定后独立 Test | 唯一正式模型 |

LightGBM的18组参数候选没有被包装成18个“模型”。阈值和权重实验作为未满足预设约束的实验结论展示，不具备部署操作。

## 4. 页面信息架构

1. **当前正式模型概览**：模型名称、任务、类别、Development与Test时期、15项特征、缩略SHA-256、冻结与完整性状态、适用范围。
2. **模型档案列表**：算法、状态、评价口径、关键指标、结论与只读详情。
3. **详情对话框**：特征方案、标签口径、参数/指标摘要、局限性和实验来源；关闭后焦点返回触发按钮。
4. **实验与稳定性**：同口径模型对比、时间折表现、Test混淆矩阵、Bootstrap区间以及阈值/权重实验结论。

页面明确解释 Production、Candidate、Historical、Baseline 与 Rejected Experiment 的含义，不使用任何无功能的训练、切换、上传、删除或部署按钮。

## 5. 可视化与评价口径

页面使用结构化JSON驱动ECharts，实现：

- Development OOF 的 RF-T2 与 LightGBM T2 综合指标分组柱状图；
- 四个时间折的 Severe Recall 折线图；
- 四个时间折的 Severe F1 折线图；
- RF-T2 2022—2023独立Test混淆矩阵热力图；
- Severe类别权重实验的Precision、Recall和F1变化图；
- Bootstrap 95%置信区间文本表。

图表纵轴从0开始，不以截断坐标轴夸大差异。RF-T2的Development OOF与独立Test分开呈现；LightGBM没有展示或虚构三级独立Test结果。阈值搜索的底层结构化数据已经进入注册表，但本页以明确的未采纳结论为主，避免形成密集且误导的参数大屏。

## 6. 真实性结论

- RF-T2在合并Development OOF上的Macro F1为0.5794，LightGBM T2为0.5654。
- RF-T2的OOF Balanced Accuracy为0.6385，LightGBM T2为0.6097。
- RF-T2的OOF Severe F1为0.3120，LightGBM T2为0.2691。
- 两种模型在四个时间折的Severe表现均有波动。
- 提高Severe权重虽然提高召回率，但显著降低Precision、F1和整体Macro F1。
- 阈值实验未在预设约束下找到可接受候选，因此不改变冻结RF-T2。
- 冻结Test混淆矩阵中，Severe→Low为31条，是辅助分析中风险最高的低估方向。
