# 第三阶段：影响等级辅助分析页面修复报告

## 修复范围

本轮仅修复影响等级辅助分析页面的选项加载、共享滚动布局、共享面包屑和用户交互文案。冻结 Random Forest T2 Pipeline、15 项特征构造、分类顺序、预测响应合同、数据库与权限规则均未修改。

## P0：输入选项加载

- 原失败请求：`GET /api/impact-options`。
- 原始现象：本地仅启动 Vite 时，请求被单页应用回退规则接管，返回 HTTP 200、`text/html` 和 `index.html`，前端随后在 JSON 解析阶段失败。Hash Router、冻结国家数据和 Python 选项生成逻辑不是根因。
- 修复：Vite 开发服务器将 `/api` 代理到只读本地 Python API；默认开发命令同时启动前端和推理 API。选项接口继续独立使用 GET，预测接口继续只允许 POST。
- 数据来源：国家、灾害类型、子类型、Magnitude 量表与语义组仍由冻结推理辅助产物和特征构造器生成，没有写死替代列表。
- 前端状态：实现 `loading`、`ready`、`blocking_error`、`retrying`；接口结构和 Content-Type 均经过校验，失败可重试且不会永久停留在加载状态。

真实浏览器验证中，国家下拉共显示 223 个条目（含占位项），灾害类型显示 32 个条目（含占位项）；刷新、直接访问 Hash 路由、路由间进入、首次失败后重试均可恢复。真实预测请求成功显示 Low、Moderate、Severe 三类模型输出概率。

## P1：共享布局与面包屑

共同滚动根因是终端子页面处于固定视口高度的 flex 高度链中，但共享子页面容器缺少明确的 `min-height: 0` 和纵向滚动职责，内容会被父容器及底部状态区裁切。修复集中在共享 `.vault-console--subpage` 和 `.terminal-page-scroll`，并统一增加 WebKit 与 Firefox 兼容的细窄终端风滚动条。管理端原有针对单页的外壳 overflow 补丁已移除；表格、对话记录等必要的内部滚动仍保留。

共享面包屑位于 `src/components/breadcrumbs.js`，由系统路由渲染入口统一挂载。它根据实际路由生成“主菜单 / 用户端或管理端 / 当前页面”，使用原生按钮、`aria-label`、`aria-current` 和 `focus-visible`，同时移除各页面遗留的重复返回条。

浏览器回归覆盖用户端总览、查询、数据分析中心、AI 问询、影响等级分析，以及管理端 Dashboard、灾害数据、用户、系统监控和模型页面。桌面 1440×900、低高度 1280×600、等效 150% 缩放 960×600 三种场景共 30 次路由检查全部通过。

## P2：VAULT-0 对话区

页面顶部改为中性功能说明；内部模型版本仅保留在小型状态标签和提示中。影响分析页只保留一个 VAULT-0 动态对话区，并支持选项加载、等待输入、加载失败、重试、分析中、分析成功和分析失败状态。旧全局悬浮 VAULT 对话不会在本路由显示。

页面统一使用“模型输出概率”，并明确说明该功能不是实时预警、不代替专业判断或决策，死亡人数、受影响人数和经济损失等事后结果不参与预测。
