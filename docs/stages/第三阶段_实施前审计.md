# 第三阶段实施前审计

审计日期：2026-08-05

## 结论

冻结模型可以在当前 Python 3.12 环境正常加载，模型 SHA-256 与最终实验 manifest 完全一致，类别顺序为 Low、Moderate、Severe。Pipeline 期望接收锁定的15项工程特征；Pipeline内部仅执行类别缺失填补、独热编码、数值中位数填补和Random Forest预测，不负责从原始请求生成地区、日期、HDI、历史频率或Magnitude稳健值。因此可以继续实现，但必须建立只读推理辅助产物，并严格区分直接输入、后端派生和Pipeline内部转换。

## 冻结模型与环境

- 模型文件大小：19,105,075字节，约18.22 MiB。
- 模型 SHA-256：`c4960347d423b1b46065c8e2fc57e1e1656fae11e1198af2fe5c6a734392a9d4`，与最终manifest一致。
- 训练/序列化记录：Python 3.12.13、joblib 1.5.3、scikit-learn 1.9.0、pandas 2.3.3、NumPy 2.5.1。
- 当前加载环境：Python 3.12.13、joblib 1.5.3、scikit-learn 1.9.0、pandas 2.3.3、NumPy 2.4.6、SciPy 1.18.0。NumPy因前一阶段安装SHAP发生小版本变化，但冻结预测已在该环境逐条复现；部署依赖仍应优先固定为训练记录的NumPy 2.5.1。
- Pipeline输入列顺序与15项T2白名单一致；模型类别顺序固定为Low、Moderate、Severe。

## 关键冻结规则

1. 日期按真实精度构造区间：日为同一天；年月为该月首日至末日；年份为当年1月1日至12月31日。只有月或年精度时`date_imputed=1`，但补出的边界不作为真实月日输入模型。
2. `historical_frequency`不是数据库实时总数。对同一国家，只统计其冻结历史事件中“事件最晚可能日期严格早于当前输入最早可能日期”的记录数。原Test特征在全量融合流程中按同一规则计算，包含2022—2023年内此前已发生的事件。为达到948条Test端到端一致，推理辅助语料必须冻结截至2023年的事件日期区间；仅冻结到2021年会造成Test不一致。该语料不包含标签或死亡结果，API也不会随数据库新增记录自动更新。对2024年及以后输入，频率表示“截至2023年冻结档案中明确早于输入日期的事件数”，并返回截止范围提示。
3. HDI只按ISO3+事件年份精确匹配，不插值、不回溯、不使用相邻年份。冻结表覆盖1990—2023；其他年份保持缺失，由Pipeline使用其已冻结的数值填补规则，同时`hdi_missing=1`并返回提示。
4. Magnitude只在8个冻结语义组中判断资格，其中Drought—Km2因Development有效样本仅1且IQR为0，不合格。合格组使用Development中位数与IQR；缺失数值、未知量表或不合格组均不生成z值。原始Magnitude不直接进入模型。
5. 冻结类别词表包含223个国家代码、17个地区、29个灾害类型、59个子类型和3种日期精度；国家—地区映射无一对多冲突，冻结数据中的63个类型—子类型配对均唯一。

## 前端与Vercel现状

- 项目为Vite原生JavaScript应用，使用Hash Router和既有登录角色守卫。
- 当前`api/`只有Node.js函数；没有Python Function、根目录requirements.txt、vercel.json或.vercelignore。
- 新页面应纳入现有用户登录路由，不重构Supabase认证。
- 模型必须保留在服务端函数包内，不能进入Vite静态资源或浏览器bundle。
- 科学计算核心包当前未压缩目录约243.74 MiB，模型约18.22 MiB，合计约261.96 MiB，尚未计入Python运行时及其他依赖。根据当前Vercel Functions指南，这低于Fluid Compute函数包上限，但冷启动、解压后体积和内存仍需实测；不应在本阶段直接正式部署。

## 风险与实施决策

- 最大风险是历史频率的时间截止口径。实现将冻结截至2023年的无标签事件区间，以复现Test并保持同一输入稳定；响应中明确披露截止日期。
- 对未知国家、未知灾害类型、未知子类型或非法类型—子类型组合返回稳定校验错误，不让未知类别静默进入模型。Magnitude量表不适用则允许预测，但返回`magnitude_group_unknown=true`和说明。
- 对2024年以后输入不外推HDI；历史频率仅依据截至2023年的冻结档案。
- Python依赖和模型体积允许继续本地原型与构建验证，但正式Vercel部署仍需在真实项目配额下测量冷启动和内存。

本审计未发现必须停止实现的未知特征规则，可以按既定顺序进入只读辅助产物构建。
