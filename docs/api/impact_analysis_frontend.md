# “影响等级辅助分析”页面使用说明

登录后从用户端菜单进入“影响等级辅助分析”，Hash Router 路由为 `#/user/impact-analysis`。依次选择国家或地区、灾害类型、灾害子类型、日期精度并填写对应格式的发生日期；Magnitude 与量表为可选项。

页面同时展示 Low、Moderate、Severe 三类模型输出概率，不把最高概率表述为确定结论或“置信度”。“模型参考信息”说明本次输入的灾害类型、地区、冻结历史频次、HDI 是否可用、Magnitude 语义组适用性和日期完整度，不声称这些信息是因果因素或贡献最大的特征。

前端只提交原始白名单字段，不计算 HDI、historical_frequency 或 Magnitude z 值，也不会把死亡人数、受影响人数或经济损失带入请求。页面沿用现有 Supabase 登录状态，不重构认证系统；预测默认不保存到数据库。
