# 冻结推理辅助产物

`ml_inference/frozen_assets/` 是只读推理快照。模型副本与原冻结 Pipeline 逐字节一致；辅助表由冻结数据和最终实验产物确定性生成，不包含标签、死亡人数、受影响人数或经济损失。

- `final_t2_pipeline.joblib`：原模型的字节级副本。
- `category_vocabularies.json`：Development 2000—2021 类别词表，用于识别编码器未见类别。
- `country_region.csv`：冻结档案国家—地区映射。
- `disaster_type_subtype.csv`：冻结灾害类型—子类型组合。
- `hdi_annual.csv`：1990—2023 年 HDRO 年度表；只允许 ISO3+事件年份精确匹配，不插值、不外推。
- `historical_frequency_intervals.csv`：截至 2023-12-31 的冻结事件时间区间及批次计数。
- `magnitude_groups.csv`：Development 阶段 8 个语义组的样本量、中位数和 IQR。
- `asset_manifest.json`：来源、截止范围、文件大小与 SHA-256。

历史频率采用保守区间规则：只有历史事件的可用日期区间上界严格早于当前事件的区间下界时才计入；同日、同月、同年或时间区间重叠的事件不会互相计入。为重现冻结的 2022—2023 测试预测，历史档案快照覆盖到 2023 年，但只使用事件标识、国家和日期区间，不读取标签或结果字段。

对于 2024 年以后请求，训练阶段没有定义动态更新规则，因此接口不补充在线事件：历史频率固定在 2023-12-31 截止状态，并明确警告；HDI 因超出冻结 1990—2023 表而保持缺失，由原 Pipeline 的冻结缺失规则处理。该方案保证相同输入可复现，但也是正式生产使用前需要治理的时效性限制。
