# 4.X 模型解释与典型案例分析

## 4.X.1 解释目标与方法

本节对已经锁定并完成时间外评价的三级 Random Forest T2 模型进行事后解释。分析对象为原始冻结模型及其既有预处理器，没有重新训练分类器、拟合新的编码规则、修改特征、调整阈值或依据解释结果改变最终方案。模型输入仍严格限定为15项无泄漏特征，输出类别顺序为 Low、Moderate、Severe。2022—2023年 Test 共948条有标签事件，每个事件恰好对应一条冻结预测；2024—2026年成熟度留置区没有进入解释过程。

为了从不同角度描述模型行为，本研究采用三种互补方法。第一，Random Forest 内置的不纯度重要性用于统计各特征在树节点分裂中获得的不纯度下降，并将独热编码后的331个维度汇总回15项原始特征。第二，在 Test 原始输入层面计算置换重要性，以 Macro F1 为评分指标，对每项特征独立随机置换30次。第三，使用 TreeExplainer 对固定分层样本计算 SHAP 值，并将独热编码维度的绝对贡献汇总回原始特征。为避免Moderate类别因样本量较大而主导汇总结果，本研究从Low、Moderate和Severe三个真实类别中各抽取104条样本，共312条。因而本文所称SHAP全局重要性是基于类别平衡分层样本计算的模型解释结果，不等同于按948条Test原始类别比例加权的总体重要性。冻结预处理器仅执行转换，没有在Test上拟合统计量。SHAP输出维度、类别轴及加和性均经过核验，重构预测概率的最大绝对误差约为 $6.0\times10^{-15}$。

三种方法回答的问题不同。不纯度重要性反映模型建树时使用特征的累计程度；置换重要性反映打乱某项原始输入后本次 Test Macro F1 的平均变化；SHAP 则把单次预测相对模型基准输出的差异分配给各特征。它们均描述模型内部的统计关联与决策依据，不构成灾害影响的因果证据。

置换前三项与不纯度排名一致，而且置换后 Test Macro F1 平均下降幅度明显高于其他特征，说明冻结模型在该 Test 时间窗口主要依赖灾害类型、子类型以及Magnitude语义组可识别状态进行区分。`magnitude_group_unknown` 的含义需要特别谨慎：它不仅表示事件无法进入7个合格Magnitude标准化组，也与灾害类别是否属于预设量表体系高度相关。该变量的高重要性不能简单理解为Magnitude工程特征本身具有很强预测能力。由于语义组资格由灾害类型、子类型及量表共同决定，`magnitude_group_unknown`与既有类别特征存在结构性依赖。分别置换该变量还可能打破这种联合结构，因此其置换重要性应解释为冻结模型对这一复合编码的敏感度，而不是该变量独立提供的净增益。

部分置换重要性为负值。例如，`magnitude_robust_z`平均为−0.0044。这表示在本次有限Test样本和随机置换下，打乱该变量没有表现出稳定的正向分类贡献，甚至平均指标略有增加；它不能被直接解释为该特征必然无效或有害。T2在先前固定Validation上的增量来自Magnitude相关特征的整体加入，而本节是在不同的Test窗口对冻结模型逐列置换，两者的估计对象并不相同。两项结果结合起来提示，Magnitude特征组的验证增量可能更多来自“语义组资格或适用状态”，而不只是标准化后的数值位置；但这一判断仍是解释性线索，尚未通过新的受控组内消融得到验证。

## 4.X.3 分类别SHAP解释

在类别平衡SHAP样本中，汇总结果再次将 `magnitude_group_unknown`、`disaster_type` 和 `disaster_subtype`列为前三项，平均绝对SHAP分别为0.1358、0.0799和0.0682。其后为HDI（0.0533）、地区（0.0368）和历史灾害频次（0.0183）。该口径给三个真实类别近似相同权重，不代表Test自然类别分布下的总体权重。由于这里汇总的是绝对值，数值仅表示影响强度，不表示特征统一推动预测向更高或更低等级变化。

在两个Severe→Low案例中，模型对Low的输出概率分别达到0.832和0.797，主要局部贡献均来自Magnitude未知组指示。两条事件的Magnitude原始值缺失，但其灾害类型属于可定义语义组，因此 `magnitude_group_unknown=0`。这一现象表明，模型可能把“属于已知语义组但本事件缺少Magnitude数值”的组合与训练期间观察到的类别模式联系起来，进而产生高输出概率的低估。然而，单个案例不能证明该组合是误判原因，更不能说明补充Magnitude后判断必然正确。

Moderate→Low两个案例均为地震，具有可用的组内Magnitude位置，但模型仍输出较高Low概率。菲律宾案例Low概率仅0.500，而Severe概率为0.332，表明该判断本身更接近决策边界。Low→Severe两个案例均为刚果（金）的病毒性疾病事件，灾害类型对Severe输出的局部贡献最大。相同国家、相同月份和相近历史频次使二者呈现相似概率结构。它们提示有限输入可能无法刻画事件局部暴露、响应过程和灾害演化，但不能由两个案例推导出流行病的一般误判规律。

## 4.X.6 预测输出概率与错误特征

Test共有678条正确预测和270条错误预测。正确组最大预测概率的中位数为0.719，IQR为0.208；错误组中位数为0.638，IQR为0.204。总体有101条错误的最大预测概率不低于0.70，说明高输出概率并不等于预测必然可靠。本研究未进行概率校准，因此预测概率仅反映冻结模型的相对输出强度，不应直接解释为经过校准的真实发生概率或可靠置信度。

三类重点错误分别为Severe→Low 31条、Moderate→Low 147条和Low→Severe 14条。其中最大概率不低于0.70的错误分别为7、73和3条。Severe→Low组最大概率中位数为0.533，HDI中位数为0.622，历史灾害频次中位数为193；该组以Flood 14条、Earthquake 9条和Storm 7条为主。Moderate→Low组最大概率中位数为0.696，以Flood 87条和Storm 44条为主。Low→Severe组最大概率中位数为0.530，其中Epidemic 5条、Flood 3条、Earthquake 2条。以上均为描述性计数，不代表灾害类型之间存在显著差异。

从真实类别的平均输出概率看，真实Low样本的平均Low概率为0.693；真实Moderate样本的平均Moderate概率为0.538；真实Severe样本的平均Severe概率为0.498，同时平均Low概率仍达到0.282。这与混淆矩阵中31条Severe被判为Low相一致，说明冻结模型对严重事件仍存在重要的低估风险。

错误组与正确组在若干输入上呈现差异。例如，正确组和错误组的HDI中位数分别为0.772和0.714；Magnitude缺失率分别为87.8%和79.6%；Magnitude未知组比例分别为49.0%和16.7%。这些现象可能受到灾害类型构成、地区分布及样本量共同影响，没有经过控制变量或统计检验，不能使用“显著差异”或“证明导致误判”等表述。

## 4.X.7 解释边界、风险与系统展示建议

首先，不纯度重要性、置换重要性和SHAP均解释冻结模型的行为，而非现实世界的因果机制。某项特征的重要性高，只表示模型较多地利用该信息；不能表述为该特征导致死亡增加。其次，SHAP使用固定分层样本而非完整Test，其数值适合描述本次样本中的模型模式，不能无条件推广到未来年份。第三，`magnitude_group_unknown`同时与量表资格和灾害类别结构关联，其高重要性存在代理变量风险。第四，置换可能生成现实中不常见的特征组合，相关重要性是依赖Test分布的性能敏感度，而不是特征的独立效应。

如果将解释结果展示在系统中，建议采用最小化、面向用户的形式：显示预测等级及Low、Moderate、Severe三类概率；列出2—3项“主要参考因素”，并明确其含义是模型贡献而非因果解释；显示HDI、月份和Magnitude等输入缺失提示；在Magnitude旁标注“仅表示同一语义组内相对位置”；统一加入“辅助分析结果，不构成专业预警或自动决策意见”的声明。论文中的完整SHAP图和置换重要性图不宜直接塞入普通用户界面，系统展示应优先保证可理解性和风险提示。

## 4.X.8 本节小结

对冻结T2模型的三种事后解释方法均表明，模型主要依赖Magnitude语义组可识别状态、灾害类型和灾害子类型区分影响等级。类别平衡SHAP样本显示，Low与Moderate输出对未知组指示较敏感，而Severe输出更依赖灾害类型、子类型和HDI。Test中仍存在31条Severe→Low，其中7条Low输出概率不低于0.70，说明高输出概率的严重低估是系统应用时必须提示的风险。由于概率未经校准，这一阈值仅描述模型输出强度。上述结果仅反映模型在当前Test样本上的统计行为，不构成灾害死亡影响的因果解释，也不能据此修改已冻结模型或阈值。
